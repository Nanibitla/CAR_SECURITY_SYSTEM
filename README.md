# Car Safety & Engine Control System

## 📌 Project Overview

This project implements a **Car Safety and Engine Control System** using **Logisim Evolution**.

The circuit accepts three inputs — **KEY, DOOR, and SEATBELT** — and controls two outputs, **ENGINE** and **BUZZER**, based on predefined safety conditions.

The project demonstrates how basic digital logic gates and Boolean expressions can be used to design a simple automobile safety system.

## 🎯 Objective

* Design a digital logic circuit for a basic car safety system.
* Control the engine based on the given input conditions.
* Generate a warning signal when an unsafe condition occurs.
* Understand the practical application of Boolean logic.
* Implement and verify a combinational digital logic circuit using Logisim Evolution.

## 🔢 Input and Output

### Input

The circuit uses three input signals:

* `KEY` – Represents the ignition key status.
* `DOOR` – Represents the door status.
* `SEATBELT` – Represents the seatbelt status.

### Output

The circuit produces two outputs:

* `ENGINE` – Indicates the engine control status.
* `BUZZER` – Activates the warning signal for unsafe conditions.

The outputs are determined by the combinations of the three input signals.

## 🧮 Logic Implementation

The circuit is implemented using basic digital logic gates such as:

* AND gates
* OR gates
* NOT gates

The input signals are combined through different logic paths to determine the **ENGINE** and **BUZZER** outputs.

The **ENGINE** output represents the required conditions for engine operation, while the **BUZZER** output provides a warning when a defined safety condition is detected.
